# Path of Exile 2 game assets

These local assets are Path of Exile 2 item artwork owned by Grinding Gear Games. They are used by Regexile, an unofficial community tool, to identify the corresponding game content.

The Path of Exile 2 Wiki was used to confirm item names and icon categories. PoE2DB provided the matching game-art paths and public CDN files because the wiki's automated-download protection blocks direct retrieval.
